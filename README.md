# 🛡️ SCAM-SHIELD

An AI-powered Scam Detection System to protect users from UPI, OTP, and Lottery frauds.

### 🚀 Features
- Detects High Risk Scams (OTP, CVV, UPI PIN, KYC Block)
- Suspicious Link Detection (bit.ly, tinyurl)
- Risk Scoring System (0-100%)
- Pattern Matching using Regex

### 🛠️ Tech Stack
- Python, Flask
- HTML, CSS
- Regex (re module)

### 📂 Project Structure
- app.py - Main Flask App
- scam_detector.py - Core Detection Logic
- templates/index.html - Frontend
- static/style.css - Styling
